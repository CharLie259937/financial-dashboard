# 金融量化分析看板 (Financial Quant Dashboard)

基于 Streamlit 的多市场（A股 / 港股 / 美股）股票量化分析看板：行情采集 → 被动/主动埋点信号 → 技术因子 → 信号效果统计 → 策略回测 → 宏观事件研究 → 前向测试跟踪，全链路 SQLite 存储，纯统计方法（无机器学习模型）。

## 功能模块

| 标签页 | 模块 | 功能 |
|--------|------|------|
| 数据采集 | — | 股票池管理、日线行情/基准指数/分红采集、宏观日历采集 |
| 数据概览 | 模块1 | 宽表：行情 + 埋点哑变量按交易日对齐 |
| 技术因子 | 模块2 | 11 类 26 列技术指标（MACD/RSI/KDJ/BOLL/量价等） |
| 信号效果 | 模块3 | 埋点信号胜率 / 超额收益统计，看空信号反向评估口径 |
| 策略回测 | 模块5 | 6 策略 × full/oos 双段 × 费率敏感性，K=3 槽位组合模型 |
| 宏观日历 | 模块6 | 宏观事件 AR/CAR 事件研究（市场模型，[-5,+10] 窗口） |
| 前向跟踪 | 模块7 | 前向测试：每日管道 / 追加式净值 / 观察名单裁决 / 数据新鲜度监控 |

另有首页「实时查询」（三市场实时报价 + K线）与「长期追踪」（阈值异动埋点）。

## 文件结构

```
dashboard.py        # 展示层：Streamlit 多标签页
quant_data.py       # 数据层：采集/表结构/统计/回测引擎/前向测试（唯一读写 SQLite）
tracker.py          # 追踪层：主动埋点行情快照 + 被动埋点阈值异动（后台线程）
daily_pipeline.py   # 每日管道入口：行情→指数→指标→信号→宽表→前向记录→新鲜度
test_module*.py     # 各模块全链路测试脚本
模块N开发计划.md     # 各模块设计决策与问题日志
```

## 本地运行

```bash
pip install -r requirements.txt
streamlit run dashboard.py
```

首次运行会自动创建 `quant_data.db`（空库）：在看板「数据采集」页添加股票并采集日线行情后，各分析模块即可使用。

## 每日管道（收盘后运行一次）

```bash
python daily_pipeline.py            # 或双击 run_daily_pipeline.bat（日志追加 daily_pipeline.log）
```

可注册 Windows 计划任务自动执行：`register_daily_task.bat`（每日 17:30）。
